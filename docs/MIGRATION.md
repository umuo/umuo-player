# Peach 播放器迁移对照

| 原能力 | 新工程处理 | 验证边界 |
|---|---|---|
| ExoPlayer 缓冲、音频焦点、解码回退 | 提取到 Media3Engine | 合成样片验证，设备差异另测 |
| 独立 GestureMachine | 直接迁入共享核心，保留来源 | JVM 测试 |
| 长按、双击、定位、亮度、音量 | 平台触控层适配 | 部分路径模拟器验证，完整手势矩阵另见验证记录 |
| 音轨与字幕选择 | Android 引擎统一轨道标识 | SRT/ASS/多音轨使用样片检查 |
| 系统画中画 | 手机入口 + 同一个引擎 | 与全屏/生命周期分别验收 |
| Peach 观看上报 | 替换为来源事件和本地位置仓库 | Emby/Jellyfin 合成协议；实服待验收 |
| Peach stream-plan / external-playback | 替换为来源 PlaybackPlan | Android 不依赖 Peach 服务 |
| Peach 字幕转 VTT | 由 Media3 读取 SRT/VTT/SSA | 不承诺复杂 ASS 特效全部一致 |
| Peach 服务端时间轴 | 不迁入 | 后续来源缩略图能力扩展点 |
| 版本/分卷/关注流专属字段 | 不迁入 Peach 模型 | 未来按通用多版本与播放队列需求实现 |
| 小窗、手势锁、字幕字体/边框设置 | 未进入最小验证闭环 | 后续产品化补齐，不宣称完整迁移 |
| Peach 馆藏管理和维护 | 不迁入 | 新播放器客户端聚焦播放与本地索引 |

新工程品牌和资源独立，AGPL-3.0 与来源声明保留。未对 Peach 项目进行修改。
