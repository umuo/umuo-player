# 视觉方向：私人影院

本轮按用户选择采用深色影院风，参考 Infuse/Plex 的内容优先思路，继续使用原生 Compose、Material 3 和 Compose for TV，不引入网页 UI 或迁移 Flutter。

## 视觉与交互

- TV 沿用 `CinemaStyle` 的黑蓝背景和暖金焦点主题。手机/Pad 在 0.1.8 使用独立的 `MobileStyle`：石墨黑 `#0D0F12`、表面 `#191C21`、琥珀强调 `#E6B66F`、暖白正文 `#F1EEE8`、辅助文本 `#969AA3`；修改手机主题不改变 TV 焦点对比度。
- 精选横幅使用来源的 backdrop，海报使用来源的 poster；WebDAV 没有图片时在后台限量提取视频帧，失败后显示媒体语义图标。
- 首页按精选、继续观看、媒体库组织；进入子目录、具体媒体库和剧集列表后隐藏精选与继续观看，返回总览再显示。手机为三列海报，宽屏为六列并增加导航栏；媒体库和设置为独立 Tab 页面，保留媒体库滚动位置。来源改为右上角切换面板，当前来源优先显示，保留编辑与草稿入口；旁边的加号直接新增。单击媒体库保留当前目录，双击媒体库返回当前来源首页并滚动到顶部。
- 继续观看来自当前来源的本地位置记录，通过索引与位置表 join 读取最多 12 条，避免逐影片查询。服务器的续播位置仍以来源详情为准。
- 手机播放器使用沉浸式画面，单击显隐控制栏，中央播放/暂停，播完显示重新播放。左右精确定位限制在媒体时长内；窄屏操作栏分成两排，保留触控区域。音轨、字幕、倍率进入独立面板，倍速选项按可用宽度换行，轨道为空时显示明确提示。诊断默认收起。
- TV 使用大图、稀疏导航与可见焦点；方向键浏览，画面聚焦时左右定位，向下进入控制栏，向上返回画面。
- 手机来源编辑使用独立页面，支持滚动与键盘调整。WebDAV 默认 HTTP / 80 / `/dav`，HTTPS 开关联动默认端口，完整地址在失焦后拆分。先保存独立草稿，认证与根目录访问成功后才替换生效配置；失败不改原凭据和观看记录。来源页可编辑或放弃草稿。TV 输入项先作为可导航按钮，按确定进入单行编辑；完成/返回结束编辑并恢复该项焦点，输入法已关闭时上下键结束编辑并移动至相邻项。左右键保留给光标。输入法本身可先消费一次返回；后续返回结束编辑，再返回页面。来源表单、搜索、匹配标题和设置令牌共用此行为。键盘高度变化后自动滚动整个编辑区，确保输入项和完成按钮可见。Pad 测试遥控器避开输入法。设置与来源页面支持滚动，校验失败保留页面；从设置/新增返回后恢复顶部入口焦点。
- 双击定位显示 ±10s，亮度与音量滑动显示百分比和进度，横滑显示目标时间，长按显示 2×。反馈独立于控制栏，在操作结束后自动消失。
- 快进间隔可选 5/10/30 秒，长按倍率可选 1.5/2/3×，滑动灵敏度可调并保存在设备。播放器锁定后拦截双击、滑动和返回，只保留解锁入口；硬件音量键仍由系统处理。
- 播放错误区分认证、网络、格式、资源失效及其他问题，提供重试与编辑连接入口；有媒体服务器转码能力时提供兼容播放，WebDAV 明确提示不提供服务端转码。

## 本地预览缓存

继续观看优先显示退出前从视频 Surface 保存的画面；播放中每 15 秒做一次兜底快照。复制不包含控件，失败后回退到现有图片。

WebDAV 原生提帧复用同源网络及 Basic/Digest 认证，串行执行，只接受 206 Range 响应，单片读取预算 16 MiB / 15 秒。图片缓存按来源 ID、媒体 ID、指纹隔离，上限 64 MiB，不写回服务器；系统清理缓存后按需重新生成。内存中的尝试记录避免同一文件反复失败重试。

普通封面的 Coil 内存与磁盘缓存也按来源 ID、协议、服务地址和账号生成独立键，避免同一图片 URL 在不同账号间共享内容。页面离开后，预览读取会检查协程取消状态，停止后续 Range 请求。

## 图片来源

`tools/fixture-art/` 内是专为合成夹具生成的两张原创图片，用于检查横幅与海报的不同裁切比例，不打入应用，也不混入用户的真实媒体库。真实图片来自 WebDAV 同目录图片、媒体服务器图片、用户主动开启的元数据服务或媒体文件的实际视频帧。

这轮属于真实工程中的 UI 实现，尚需继续做真机字号、无障碍、长标题、多语言、海报缺失与大库性能验证。不要把一张合成截图当作全部产品体验验收。

## 影视库与连接统一

WebDAV 的“文件浏览 / 影视库”位于明确的双模式入口。影视库只读取 NFO 或明确元数据匹配，原始文件名和孤立海报不会使视频进入影视库；按电影/剧集、类型、标签与合集组合筛选。剧集按来源和目录身份聚合，继承 `tvshow.nfo` 的资料，分集仍使用原视频身份播放。缺失分类不生成虚构标签。模式按来源保存在本机。

Emby/Jellyfin 使用服务器影视库，提供媒体库、电影、剧集入口，不显示文件模式切换，不要求本机扫描 NFO。电影与剧集通过服务器递归分页检索，详情显示返回的类型和标签。

三种来源的连接表单都使用主机、端口、路径与 HTTPS；WebDAV 默认 80/443、`/dav`，Emby/Jellyfin 默认 8096/8920、`/`。切换协议或 HTTPS 仅联动当前默认端口，保留自定义值；完整 URL 在失焦后拆分。TV 使用同一地址策略，遥控按钮切换 HTTPS。

## 0.1.3：筛选、扫描与公网 WebDAV

筛选默认折叠，用户主动展开。折叠不清除已选条件，保留摘要和清除入口。类型/标签同名且成员相同时不重复显示；筛选项显示数量，合集兼容普通/嵌套 NFO set、多合集与剧集聚合。整个库都属于同一合集时，不展示无法缩小结果的重复选项。

扫描速率和自动预览提帧可在设置中控制，策略和边界见 [扫描说明](SCANNING.md)。播放前的 Range 探测支持 OpenList 的有界直链跳转，跨源不带来源凭据，HTTPS 不降级到 HTTP，继续使用系统证书校验。签名直链只进入临时播放计划，媒体索引保留原 WebDAV 地址。


字幕默认更靠近视频底边，使用透明底、白字描边。TV 正常播放隐藏底部控制栏，下键唤出并聚焦播放控制，上键回到画面并收起，暂停与失败时显示。


TV 版在 Pad 上保留原 TV 布局，通过普通桌面入口打开，右下角可展开触控测试遥控器。字幕列表以中文语言与用途为主标题，原文件名小字保留；不翻译文件名或字幕正文。

## 0.1.8：选定设计图的原生手机实现

视觉参考为 [Android 首页设计图](design/android-home-reference.png)。继续使用 Kotlin Compose、Material 3 和现有图片加载器，无新增 UI 框架或字体下载。图中海报属于影视内容，运行时从当前来源获取，不把示例片名、生成海报或整张设计稿嵌入应用。

- 顶部保留来源切换和新增，窄屏按字体缩放为来源名称预留宽度。底部仅保留媒体库/设置，以图标和文字着色表达选中，不显示大胶囊指示器。
- 精选/电影/剧集为紧凑文字入口；精选背景延伸到导航后方，并渐隐到页面底色。优先使用续看中的电影背景，没有可用背景时不强行生成横幅，加载失败则收紧横幅高度。
- 主按钮统一显示「播放」，沿用实际续播逻辑；点击精选片名进入详情。时长与类型只展示已知资料。
- 手机续播横向队列按当前宽度完整显示两张卡，展示真实上次画面、进度和剩余时间；分集优先以剧集名加季/集信息显示。查看全部进入独立列表，返回恢复原首页滚动位置。
- 海报保持三列，宽屏六列；目录保持横图网格。区块和卡片文字明确指定行距，避免较小字号继承默认大行高。图片、标题和状态来自真实媒体记录。
- WebDAV 文件模式、影视库和扫描位于「媒体库选项」菜单；类型/标签/合集由筛选图标主动展开，选中条件后面板仍保持展开。Emby/Jellyfin 的续看、下一集、最近添加、收藏、合集等保留在同一菜单，搜索按需展开。
- WebDAV 没有入库时间字段，首页列表继续标为「影视库」，不把源 ID 的排序标成最近添加。服务器的最近添加入口仍调用对应服务接口。

实际原生对照和验收见项目根目录 `design-qa.md`。手机系统栏属于 Android，不以生成图里的无系统栏画面覆盖或仿造系统区域。

## 0.1.9：文件与影视库模式入口常驻

用户反馈进入影视库后找不到文件浏览。模式选择从会变化的内容导航中独立出来，固定在来源标题下面；两个模式同时显示，当前模式使用图标、琥珀文字和下划线标识。滚动列表、筛选、分集/详情和全部续播视图均不会藏起另一个模式。

文件浏览专注目录与文件，影视库保留海报、精选和电影/剧集分类。模式切换回到对应首页并清理旧目录层级；扫描仍在模式行右侧的工具菜单。Emby/Jellyfin 沿用服务器影视库入口，不显示 WebDAV 文件模式。

本次可发现性要求优先于 0.1.8 生成图的首屏容量：新增常驻模式行，不把返回入口收进隐藏菜单。列表换结构后用下一次布局的顶部定位，避免旧条目锚点把分类导航留在屏幕外，接口依据 [LazyListState 官方说明](https://developer.android.com/reference/kotlin/androidx/compose/foundation/lazy/LazyListState#requestScrollToItem(kotlin.Int,kotlin.Int))。
